# Sticky Notes — 本地便签管理器页面设计方案

> **状态**：📐 设计完成 / 准备实现  
> **关联后端**：基于 SQLite WAL 模式（`notes.db`）与 `SqliteNoteRepository`  
> **前后端架构**：WebView2 + Vue 3 + TypeScript + Tailwind CSS + IPC 强类型通道

---

## 1. 设计目标与核心定位

本地便签管理器（Sticky Notes Manager）是一个**集中化管理、检索、统计与批量操作**所有便签的控制中心窗口。

- **脱离前端单便签上下文**：不依赖单个便签窗口的 DOM/IPC，直接通过 Native 层的 `SqliteNoteRepository` 操作 `notes.db` 底层数据库。
- **双向联动**：
  1. 在管理器中修改便签（如修改标题、调整可见性、删除），可实时反映到桌面已打开的便签窗口。
  2. 桌面便签内容变动时，管理器能够自动感知（通过 IPC 广播事件或 DB 变更监听）并刷新界面。
- **现代化体验**：支持全局全文模糊搜索、事项进度统计大盘、卡片/列表双视图、标签筛选、回收站/归档、以及 Markdown/JSON 批量导出导入。

## 3. 核心功能模块设计

### 3.1 概览大盘与侧边导航
- **全局指标统计**：便签总数、待办事项总数、完成率（%）、今日待办数。
- **快速状态过滤**：
  - 全部便签（All Notes）
  - 桌面活跃中（Active on Desktop, `visible = 1`）
  - 桌面已隐藏（Hidden, `visible = 0`）
  - 包含未完成条目（Pending Tasks）
  - 全部已完成（Completed）
- **标签/分类管理**：支持从便签标题/内容提取 `#标签` 或自定义颜色分类。

### 3.2 列表与卡片主视图
- **卡片视图（Grid View）**：
  - 按照便签自身设定的背景色高保真渲染迷你卡片。
  - 显示便签标题、前 3 条待办项预览、未完成进度徽章、最后更新时间。
  - 卡片右上角操作浮层：一键桌面唤起/隐藏、置顶开关、删除。
- **列表视图（Table View）**：
  - 适合密集型管理，支持按标题、更新时间、事项数、状态排序。
  - 支持多选（Checkbox）进行批量操作。
- **全文实时搜索**：
  - 输入即搜，同时匹配便签 `title` 以及子项 `note_items.content`。
  - 搜索命中关键字高亮展示。

### 3.3 详情与快捷编辑侧栏
- 点击任意卡片/列表项，右侧滑出详情抽屉：
  - **基础元数据修改**：实时修改便签标题、背景色、透明度、置顶状态。
  - **待办列表交互**：支持直接在管理器里勾选完成、新增待办、修改文本、拖拽排序、删除待办。
  - **桌面联动动作**：
    - `在桌面上定位/显示`（如果已打开则高亮并置顶窗口；如果隐藏则拉起）。
    - `关闭桌面窗口`（仅保留数据，释放 WebView2 原生资源）。
  - **导出/分享**：导出为 Markdown 文本、ICS 日历格式、JSON 备份。

## 4. 前后端通信协议（Manager IPC 扩展）

在 `host/WebMessageDispatcher.h` 与前端 `ipc.ts` 契约中，扩展管理器专属的强类型消息：

### 4.1 Web → Native（管理器发送给宿主）
| 事件名 | 参数 (`data`) | 说明 |
| :--- | :--- | :--- |
| `mgr_list_all` | `{ keyword?: string, filter?: string }` | 请求获取所有便签列表及统计信息 |
| `mgr_get_note` | `{ name: string }` | 获取指定便签的完整详细数据（含全部 items） |
| `mgr_create_note` | `{ title?: string, color?: string }` | 创建新便签并存入 SQLite |
| `mgr_delete_notes` | `{ names: string[] }` | 批量删除便签（级联删除 items，并通知关闭桌面窗口） |
| `mgr_toggle_visible` | `{ names: string[], visible: boolean }` | 批量控制便签在桌面的显隐状态 |
| `mgr_update_note` | `{ name: string, ...changes }` | 修改便签属性（标题/颜色/透明度等） |
| `mgr_export` | `{ names: string[], format: 'md'|'json' }` | 导出选中便签数据 |
| `mgr_locate_window` | `{ name: string }` | 在桌面上激活并居中/闪烁该便签窗口 |

### 4.2 Native → Web（宿主推给管理器）
| 事件名 | 数据 (`data`) | 说明 |
| :--- | :--- | :--- |
| `mgr_data_changed` | `{ action: 'create'|'update'|'delete', name: string }` | 外部便签数据变更广播，触发局部或全量刷新 |
| `mgr_note_list` | `Array<NoteSummary>` | 返回便签列表及统计概要 |
| `mgr_note_detail` | `NoteDetail` | 返回单个便签详情 |
